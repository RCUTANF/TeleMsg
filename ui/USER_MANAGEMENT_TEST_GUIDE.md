# 用户管理功能测试指南

## 测试环境准备

1. 确保后端服务已启动
2. 确保前端应用已启动
3. 使用管理员账号登录系统
4. 进入管理中心 -> 用户管理页面

## 测试用例

### 测试用例 1: 查看用户列表
**目的**: 验证用户列表正确加载并显示

**步骤**:
1. 打开管理中心
2. 点击左侧菜单"用户管理"
3. 观察用户列表

**预期结果**:
- ✅ 用户列表正确加载
- ✅ 显示用户头像、姓���、用户名
- ✅ 显示角色、部门、状态
- ✅ 显示最后活跃时间和加入时间
- ✅ 每行有编辑和删除按钮

---

### 测试用例 2: 添加新用户
**目的**: 验证创建新用户功能

**步骤**:
1. 点击"添加用户"按钮
2. 填写表单：
   - 用户名: `test_user_001`
   - 密码: `Test@123456`
   - 姓名: `测试用户`
   - 邮箱: `test@example.com`
   - 手机号: `13800138000`
   - 角色: `普通员工`
   - 部门: 选择一个部门
3. 点击"保存"按钮

**预期结果**:
- ✅ 显示成功提示 "用户创建成功"
- ✅ 对话框自动关闭
- ✅ 用户列表自动刷新
- ✅ 新用户出现在列表中

**测试数据变体**:
- 测试不同角色（普通员工、部门主管、系统管理员）
- 测试不选择部门
- 测试不填写可选字段（邮箱、手机号）

---

### 测试用例 3: 表单验证
**目的**: 验证表单必填项验证

**步骤**:
1. 点击"添加用户"按钮
2. 尝试不填写必填项直接保存
3. 尝试只填写用户名不填写密码
4. 尝试只填写密码不填写姓名

**预期结果**:
- ✅ 显示错误提示 "请填写用户名和姓名"
- ✅ 显示错误提示 "请输入密码"
- ✅ 表单不会提交
- ✅ 对话框保持打开状态

---

### 测试用例 4: 编辑用户信息
**目的**: 验证更新用户信息功能

**步骤**:
1. 在用户列表中找到一个用户

3. 修改用户信息：

   - 邮箱: `updated@example.com`
   - 角色: 改为 `部门主管`
4. 点击"保存"

**预期结果**:
- ✅ 对话框打开并预填充用户信息
- ✅ 用户名字段为禁用状态（不可修改）
- ✅ 不显示密码字段
- ✅ 显示成功提示 "用户更新成功"
- ✅ 用户列表刷新显示更新后的信息

## API 集成测试

### 测试用例 15: API 调用验证
使用浏览器开发者工具 Network 面板观察：

**创建用户**:
- 请求: `POST /auth/register`
- 验证请求体包含所有必要字段
- 验证响应返回用户对象

**更新用户**:
- 请求: `PUT /users/{userId}`
- 验证请求体只包含更改的字段
- 验证响应返回更新后的用户对象

**删除用户**:
- 请求: `DELETE /admin/users/{userId}`
- 验证响应状态码 200
- 验证返回成功消息

**获取用户列表**:
- 请求: `GET /admin/users`
- 验证返回用户数组
- 验证每个用户对象包含必要字段

## 边界条件测试

### 测试用例 16: 边界值测试
**测试数据**:
1. 用户名：
   - 最短（1个字符）
   - 最长（100个字符）
   - 包含特殊字符
   - 包含中文

2. 密码：
   - 最短（6个字符）
   - 最长（50个字符）
   - 包含特殊字符
   - 纯数字/纯字母

   - 标准格式

## 已知问题和限制

1. 用户名创建后不可修改
2. 删除操作不可恢复
3. 批量操作暂不支持
4. 用户状态切换功能已预留但未在 UI 中启用

# 添加部门成员功能完善

## 问题描述
在 `DepartmentMembersDialog` 组件中，"添加成员"按钮没有对应的功能实现，是个无效按钮。

## 解决方案

### 1. 创建了 AddDepartmentMemberDialog 组件
**文件**: `ui/src/app/components/AddDepartmentMemberDialog.tsx`

这是一个完整的添加部门成员对话框组件，具有以下功能：

#### 核心功能
- **用户列表展示**: 显示所有可添加的用户（排除已在部门中的成员）
- **搜索功能**: 支持按用户名、账号或部门搜索
- **多选功能**: 支持批量选择多个用户
- **实时反馈**: 显示已选择的用户数量

#### UI特性
- **可视化选择**: 
  - 未选中：空心圆圈
  - 已选中：紫色实心圆圈带对勾
  - 选中项高亮显示（紫色背景）
- **用户信息展示**:
  - 头像
  - 姓名和用户名
  - 当前部门（如果有）
  - 角色（如果有）
- **滚动区域**: 处理大量用户时提供良好的滚动体验
- **加载状态**: 显示加载中的提示

#### 交互设计
- 点击整个用户卡片即可选择/取消选择
- 底部显示可添加用户总数
- 选择计数显示在对话框描述和按钮上
- 禁用状态：没有选择用户时按钮不可用

### 2. 更新了 DepartmentMembersDialog 组件

#### 新增内容
- 导入 `AddDepartmentMemberDialog` 组件
- 添加状态管理：`addMemberOpen`
- 为"添加成员"按钮添���点击事件处理
- 集成 `AddDepartmentMemberDialog` 组件并传递必要的属性

#### 数据流
```
用户点击"添加成员" 
  → 打开 AddDepartmentMemberDialog 
  → 用户选择要添加的成员 
  → 调用 API 添加成员 
  → 刷新部门成员列表
  → 显示成功提示
```

### 3. 扩展了 API 服务

**文件**: `ui/src/app/services/api.ts`

新增方法：
```typescript
async addDepartmentMembers(departmentId: string, userIds: string[]): Promise<void>
```

**功能**: 批量添加用户到指定部门

**API 端点**: `POST /admin/departments/{departmentId}/members`

**请求体**:
```json
{
  "userIds": ["userId1", "userId2", ...]
}
```

## 使用流程

1. 在管理中心进入"组织架构"
2. 点击某个部门的"成员"按钮
3. 在部门成员对话框中点击右上角"添加成员"按钮
4. 在弹出的对话框中：
   - 浏览��搜索用户
   - 点击用户卡片选择/取消选择
   - 查看底部已选择数量
5. 点击"添加"按钮完成操作
6. 自动刷新成员列表

## 技术实现细节

### 状态管理
- `allUsers`: 所有系统用户
- `selectedUserIds`: 已选择的用户ID集合（使用 Set 避免重复）
- `isLoading`: 加载用户列表状态
- `isAdding`: 添加成员操作状态

### 数据过滤
1. 过滤掉已在部门中的成员
2. 根据搜索关键词进一步过滤
3. 实时更新可选用户列表

### 错误处理
- 加载用户失败：显示错误提示
- 添加成员失败：显示错误提示
- 未选择用户：按钮禁用状态

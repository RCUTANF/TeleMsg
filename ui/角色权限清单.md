# 角色权限清单

本清单详细列出了系统中的所有可用权限，按功能类别进行组织。

---

## 审批功能

| 权限ID | 权限名称 | 描述 |
| --- | --- | --- |
| `approve.all` | 审批全系统所有操作申请 | 跨部门审批、全局操作审批、最终审批决策权 |
| `approve.dept` | 审批本部门操作申请 | 如设置批规则、导出本部门数据等 |
| `approve.cross` | 发起跨部门审批申请 | 跨部门群聊创建、数据调用等 |
| `approve.sensitive` | 发起敏感操作申请 | 大文件传输、跨部门聊天、本部门群聊创建等 |
| `approve.view` | 查看个人审批申请进度 | 查看个人申请状态 |

## 数据与文件管理

| 权限ID | 权限名称 | 描述 |
| --- | --- | --- |
| `data.export.all` | 导出全系统数据 | 查看和导出全系统数据（需审批） |
| `data.export.dept` | 导出本部门数据 | 查看和导出本部门数据（需审批） |
| `data.clean` | 清理违规数据 | 删除违规内容 |

| `file.receive` | 接收文件 | 接收并下载文件 |
| `file.manage` | 文件管理 | 管理共享文件 |
| `file.export` | 导出文件数据 | 导出聊天和文件数据 |

## 群组与部门管理

| 权限ID | 权限名称 | 描述 |
| --- | --- | --- |
| `group.manage.all` | 创建/管理任意群聊 | 审批跨部门群聊创建申请 |
